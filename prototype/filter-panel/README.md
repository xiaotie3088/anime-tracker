# 原型：筛选面板（五层 + 三态）

一次性的可交互原型，只回答一个问题：

> **这个「五层 + 三态（不选 / 含 / 不含）」的筛选面板，点起来顺不顺手、看不看得懂？**

对应票：`.scratch/filter-modes/issues/01-筛选面板推翻重做.md`（用户要求"先做原型看手感，认可后才写正式代码"）。

## 怎么看

**双击 `index.html`**（或右键 → 用默认浏览器打开）。不用起服务、不用联网：数据已经烧进 `data.js`。

- 屏幕**底部居中的黑条是原型专用的**，不属于被测设计：
  - `←` / `→` 换 A / B / C 三个**结构**变体（键盘 `←` `→` 也行）；
  - 三个开关是票里**没定死**的三个点，用来当场对比：
    1. **选中项置顶**（票要求"移"，关掉能看到"列表会不会跳"）；
    2. **部数口径**（三档循环，票 §三.4 只是其中第一种）；
    3. **状态 chip 交集 / 并集**（默认沿用**线上 = 交集**：多选要同时满足，所以同时点「放送中」
       +「未开播」会一部都不剩；底部可切成并集对比）。
- 面板里的一切都真的会动：三态循环、置顶、折叠展开记忆、实时部数、排序、每行几部、搜索框。

## 三个变体的差别（是结构，不是换色）

| 变体 | 结构 |
| --- | --- |
| **A** | 票的规格：五层竖排（搜索 / 状态 / 四个折叠维度 / 排序 / 每行几部） |
| **B** | 排序 + 每行几部收进一个默认收起的「显示方式」，面板只剩 状态 + 四个维度 |
| **C** | 维度分两栏（≥1080px），类型标签用两列网格 + 自己的滚动区，少滚一点 |

## 动手前先知道：一处票里的口径会自相矛盾

票 §三.4 写「选项右侧的部数 = 如果现在点它（含），会剩下多少」。因为三态是**循环**的，
"点它会怎样"取决于它现在的状态，于是同一个位置的数字会换含义：

实测（真实数据）：点一下「奇幻」→ 列表变成 **31 部**，而「奇幻」那个按钮自己写着 **141**
（= 172 − 31，"改成不含会剩 141"），旁边没选中的「科幻」写着 **15**（= 含它剩 15）。
141 与 15 并排，很容易被读成"奇幻有 141 部"。

所以原型把三种口径都做出来了，底部工具条循环切换：

| 口径 | 含义 | 代价 |
| --- | --- | --- |
| `点它剩多少`（票 §三.4） | 点它一下之后剩多少 | "含"着的项数字会变成"改不含之后"的部数，和列表头对不上 |
| `列表里有几部` | 现在列表里有几部含它 | 永远和列表头对得上；被排除的项自然是 0（正好是票里备选的那句"显示为 0"） |
| `固定基数`（线上旧口径） | 只按搜索框 + 状态算 | 数字不随筛选跳动，但要人自己反推"点下去会剩多少" |

## 其他几处我先拍的决定（不同意就说，改起来很快）

1. **去掉了「筛选 / 排序」总开关**：按票的图，搜索框是面板第 1 层，面板常显。
   （面板第 1 层是**常驻节点**，点筛选不会重绘它 —— 这样搜索框的光标不会丢，票的这条验收才成立。）
2. **第 2 层状态 chip 默认沿用线上行为（交集）**：多选要同时满足，所以同时点「放送中」+「未开播」
   会一部都不剩。底部可切成"并集"对比 —— 默认不动，免得把线上旧行为混进"新手感"里一起评价。
3. **被排除的项留在候选列表里**（票允许"显示 0 或干脆不出现"）：不然它就只能去底部的条件条点回来，更绕。
4. **搜索框只搜中文名 / 原名**（和线上一致），不做标签文字搜索（票里明确不做）。

## 刻意不做

- 不碰 `web/app.js`、`src/`、`data/anime.db`；不调接口；**没有测试**（原型不该有测试）。
- 顶栏与卡片是静态替身；卡片上的「追番 / 补番 / 移除」只在内存里改，好让"我追的"那个数字真的会跳。
- 不做筛选方案收藏、不做侧边栏筛选（票里明确不做）。

## 提醒：原型不是实现，别把它搬进产品代码

票里有一句「不要在原型里写业务逻辑（真实筛选、API 调用）」。这里的处理是：
**不调 API**（数据是烧进来的快照），但为了让票要求的"部数变化"真能动，`proto.js` 里有一份
**内存里的三态过滤**（约 60 行，`passes()` / `resultItems()` / `optionCount()`）。

它是**一次性的**：正式实现时 `web/app.js` 要按票的清单重写（`state.filters` 改成
`{ include, exclude }`、重写 `applyFilters()`、`activeFilterChips()` 区分含/不含、
在 `scripts/ui-smoke.ts` 里给每个交互加断言）。**不要把 `proto.js` 直接搬过去** ——
原型里的代码是在"能点就行"的约束下写的。
