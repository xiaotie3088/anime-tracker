原型这是在回答一个问题：这个「五层 + 三态（不选 / 含 / 不含）」的筛选面板，点起来顺不顺手、看不看得懂？

一次性的可交互原型，不是产品代码：没有改 web/app.js，也不调接口、不碰数据库。 样式直接用 web/styles.css 的真实令牌，所以深浅两套主题都跟着系统走。 数据是 — 这季的真实快照（—）， 部数、候选顺序、列表长度都是真的 —— 手感才可信。

顶栏的「季度 / 更新数据 / 更多」与卡片布局是静态替身；筛选面板里的每个按钮都真的会动 （三态、置顶、折叠、实时部数、排序、每行几部、搜索都在跑）。快照时间 —。

顺手试这 4 件事：① 随便挑个标签，点一下 / 两下 / 三下，看三态的差别和列表变化； ② 看选项右边的数字 —— 尤其已经"含"的那个自己写着多少（票的口径在这里会露馅， 底部可以切成另外两种口径当场比）；③ 在搜索框里打几个字再点筛选，看光标有没有丢； ④ 点开「类型标签」，注意选中后它会不会被收起、选中项有没有跳到最前面。

屏幕底部居中的黑条是原型专用（不属于被测设计）：← → 换 3 个结构变体 （键盘 ← → 也行），右边三个开关是票里没定死的三个点，可以当场对比 —— 其中「状态 chip」默认沿用线上行为 = 交集，这样不会把旧行为混进"新手感"里一起评价。
