# UI 改版设计说明 · 放送表

> 轮次：01（方向探索 → 落地）
> 范围：`web/` 全部界面；不改后端接口与数据规则。
> 对比页：`style-explorer.html`（方向 A / B / C + 改版前基线）

## 一、这个产品与用户任务

「新番追番日历」是本地优先的单机工具，面向**追当季新番、同时补老番**的人。

- 每天打开一次，最想知道：**今晚有没有更新、下一集是什么、几点、还差几天**。
- 隔一段时间打开，最想知道：**我追到第几集、补番库还欠多少、有没有哪部被改档**。
- 使用场合：桌面浏览器，夜里居多；数据在自己手里，不登录、不云同步。

因此首屏不是「展示我收藏了多少番」，而是**一张能读的放送时刻表**；补番是紧挨着它的第二件事，不该被塞进另一个页面才看得见。

## 二、北极星

**「像一张当天就能读的节目表：时间有刻度，空格也有意义。」**

主操作是「看下一集 / 记一集进度」，不是「浏览海报」。所以时间、集数、倒计时是主角，海报只负责认脸。

## 三、标杆与取舍

品类：番剧放送表 / 追番管理。参考了：

- **MyAnimeList 当季番剧页**（`shots/ref-mal.png`）：海报网格 + 筛选条，海报承担识别，标签很轻。
- **AnimeSchedule.net**（`shots/ref-animeschedule.png`）：顶部 7 列星期，下面按天铺海报。
  两张实际画面都被 cookie 弹层遮住，读到的是布局骨架，不是完整视觉；配色与字号未照抄。
- 现有版本的 7 列等宽周视图（`shots/baseline-week.png`）：同样属于品类默认版式。

**沿用**：海报认脸、星期分组、集数与进度并排、番名可复制。
**换掉**：

1. 7 列等宽 → **按当天集数加权的 7 列**：空白天压成 46px 竖条，有番的天按集数分宽度。
   理由：一周 7 集时，等宽列有两天完全没有内容，却和两集的那天一样宽。
2. 「接下来要更新的」沉到页尾 → **页首一条下一集横条**。理由：这是每天打开时唯一必看的信息。
3. 筛选台式的总览 → **季度条 + 一行搜索 + 默认收起的筛选抽屉**。理由：126 部番的浏览不该先穿过五层筛选。
4. 我的追番的碎按钮 → **书架卡 + 可拖动的集数刻度**。理由：补番关心的是「还欠几集」，按钮不是主角。
5. 青绿→蓝紫渐变 → **纸色 + 墨色 + 一点朱红**。朱红只给「今天 / 下一集 / 选中 / 进度」，别处退成墨与灰。

## 四、方向卡（选定：A 放送表）

| 字段 | 决定 |
| --- | --- |
| 北极星 | 像一张当天就能读的节目表：时间有刻度，空格也有意义。 |
| 调性 | 安静（夜里看不刺眼，饱和度预算只给朱红）· 精致（1px 发丝线、严格对齐到 4px 网格）· 中高密度（一屏看到整周与补番）· 中等分量（墨色实心只给主操作与今天）· 偏庄重（直角、无圆角、无拟物阴影） |
| 生成引擎 | **印刷节目表**：报头、栏线、时间栏、加权的日期列。来自「番剧放送表」这个实物，不是通用的卡片后台。 |
| 首屏骨架 | 页首「下一集」横条（约 80px）→ 周工具行（约 48px）→ 加权 7 列周板（约 360px）→ 接下来更新的两列表格。首屏能看到整周 7 集与补番入口。 |
| 页面结构 | 单列工作区；周视图主区 + 下方「接下来」；总览为季度条 + 抽屉 + 卡片网格；我的追番为分类分段 + 双列书架。 |
| 字体 | 标题与正文：微软雅黑 / 苹方，标题 800；时刻、集数、倒计时：Cascadia Mono / Consolas，等宽数字；正文 14.5px，辅助 13px，标题 16–28px，下一集数字 40px。 |
| 色彩 | 浅色：纸 `#efece4`、表面 `#f8f5ee`、墨 `#14161a`、朱红 `#b8331b`、线 `#d3ccbe`。深色：底 `#111312`、表面 `#191b1a`、纸字 `#efebe1`、信号 `#ff5a36`。来自旧报纸与深夜节目表的纸墨关系，朱红来自「正在放送」的信号灯。 |
| 主视觉 | 排版本身：加权周板 + 等宽时刻。没有插画、没有大图；海报只做 44×62 的识别块。 |
| 图标 | 不用图标库。字符与编号：`◈` 报头、`‹ ›` 翻周、`✓ / ⊘` 筛选态、`×` 关闭。 |
| 控件语法 | 2px 圆角、1px 墨线、实心墨按主操作、朱红只做信号；按下位移 1px；选中用实心块 + 前置 `✓`；没有渐变按钮。 |
| 动效 | 「咔嗒」：按钮按下 120ms 陷 1px 回弹；视图切换 220ms 上浮 6px 淡入；筛选抽屉 180ms 从触发点展开；倒计时数字每 30 秒原地更新，不滚动。 |
| 结构性突破 | 空白天不占等宽，而是压成竖条；今天用反色表头压住。周的「密度」一眼可见。 |
| 记忆点 | 周板里今天那列的反色表头 + 页首下一集的大号等宽倒计时。 |
| 放弃什么 | 渐变主按钮、彩色胶囊标签、五层筛选面板常显、四列等宽的空白天、每张卡片都带阴影。 |

**差异检验**：A 的骨架是加权周板 + 右栏书架；B 是左右跨页手帐；C 是海报英雄 + 横向卡带。字体分别是等宽 + 黑体 / 宋体 / 超粗无衬线；色彩分别是纸墨朱红 / 奶油柿红鼠尾草 / 近黑荧光绿；主视觉分别是排版 / 手帐与印章 / 整块海报。四项无一项相同，且 A 与 B 都打破了「7 列海报网格」的品类套路。

## 五、关键界面决定

- **周板**：`flex` 权重 = 当天集数 + 0.5（一集也至少占 1.5 份，空天固定 46px）；今天反色表头 + 3px 朱红内阴影；深夜番保留「深夜番」标记，不改变星期归属规则。窄于 1180px 时收成按天堆叠，卡片在宽列里把时刻/倒计时挪到右侧（容器查询），避免挤成一条。
- **落地取舍**：A 的首屏有右栏「待补书架」；落到整站时，补番放进「我的追番」的双列书架，周视图保持整周宽度，不再额外加一条右栏。右栏书架只在方向对比页里留档。
- **下一集**：取 `/api/week` 的 `upcoming[0]`，大号等宽倒计时 + 集数进度；无下一集时整条不渲染。
- **总览**：季度条只保留「可多选 / 历史不删」一句；筛选默认收起，展开后状态一行、四个维度两列、显示方式一栏；部数口径与三态规则完全沿用原实现。
- **我的追番**：分类分段控件；双列书架，进度条仍是真实的 `input[type=range]`（`input` 只画、`change` 才写库），底下用一集一格的刻度（超过 24 集按比例压格）；分类下拉保留四个分类；书架卡显示剩余集数与预估时长。
- **变更**：日期时间线 + 类型标记；空状态只留一句。
- **详情**：纸张式弹窗，封面 116×162，字段两列，分集表用等宽时刻；底部操作条常驻。
- **主题**：默认跟随系统；右上角「更多 → 主题」可以强制浅色 / 深色并记住选择（`auto` 时不加 class，交给 `prefers-color-scheme`）。深色令牌与浅色同一套变量名；颜色全部走 `web/styles.css` 的令牌。

## 六、动效清单

1. 主操作反馈：所有按钮按下位移 1px + 背景加深；主按钮 hover 提亮；筛选 chip 选中时实心块立即到位。
2. 状态切换来路：视图切换 220ms 上浮淡入；筛选抽屉 180ms 展开；弹窗 180ms 上移淡入；分类切换重绘沿用同一入场。
3. 首次进入：`#app` 的直接子块按 40ms 间隔依次上浮，总时长不超过 600ms；仅在切换视图时播放。
4. 减少动态效果：`prefers-reduced-motion: reduce` 下全部过渡与动画关闭，内容直接到位。

## 七、功能建议（本轮不做，等确认）

1. **周视图直接「+1 集」**：现在要记进度得进详情或我的追番。建议在周卡片上给一个「看完了」小按钮，点完立即写库并让卡片转为已看态。
2. **补番计划入口**：数据层已有 `planned_weekday_jst` / `planned_eps_per_day`，界面没做。可以做成「这周补哪几部、每天几集」，把补番从被动的书架变成可排期的计划。
3. **键盘快捷键**：`J/K` 在周板移动、`Enter` 开详情、`Space` 标记看完、`[` `]` 翻周。对每天用的本地工具收益很高。
4. **空白天推荐**：周三、周六没有更新时，用补番库里「剩余集数最少」或「优先级最高」的一部填一格，解决「今天看什么」的空档。
5. **搜索入口**：导航里没有加番入口，现在只能 `pnpm add`。如果愿意，可以把「加番」收进「更多」菜单，不占主视线。

## 八、独立评审与修正

第 1 轮：独立评审者只看截图与任务，不看源码，**7.7 / 10**。结论是方向站得住、首屏答得快，
扣分集中在「可信」和「手感」。

已修：

- 详情弹窗把「放送」改成「放送档」、「首播」改成「首集」，加一句解释三种时间的关系；
  分集源站只给日期时显示「周四（日期）」，不再用 00:00 冒充精确时刻；当前集加「下一集」标记。
- 进度手柄从 8×20 加到 10×22，轨道 10px、拖拽命中区 24px；一集一格的刻度保留。
- 更新范围对话框改成左右两栏：季度格在左、重抓开关与摘要在右，30 个季度不再把底部按钮顶出屏幕；
  删掉与勾选框重复的跳过说明与重复的耗时描述。
- 变更空状态补上「点右上角『更新数据』同步一次」的下一步。
- 页签名「我的追番」统一用全库口径（32），不再出现周视图 9 / 我的追番 32 的分裂。
- 周卡片「已更新」改成「已播出」，避免和紧挨着的「已看 0 / 12」混读；短倒计时加 title 显示精确时长。
- 390px 下「下一集」的「看到 1 / 12」不再被拆成孤字。

评审的误报：浅色预览里同时出现的两枚条件是「含 奇幻」和「⊘ 不含 成人」，不是同一个值；
三态逻辑（含 / 不含 / 不选）没有改动，也不会让一个值同时落在两侧。

未采纳：总览卡片网格「没有放送表语法」（总览是检索目录，周板才是时刻表）、
「接下来要更新的」与本周重叠（它是跨周前瞻）、1024 海报被裁方（实际仍是 44×62，截图缩放误读）。
